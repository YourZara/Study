1. ASCII code; (−28 + 12)10 in 8-bit 2's complement [1+3]

ASCII (American Standard Code for Information Interchange) is a 7-bit alphanumeric code that represents 128 characters (letters, digits, punctuation, control codes) – e.g. 'A' = 1000001 (65), 'a' = 1100001 (97), '0' = 0110000 (48). An 8th bit is often added as a parity bit.

(−28) + (+12) in 8-bit signed representation

+28        = 0001 1100
1's compl. = 1110 0011
+ 1        = 1110 0100   ← −28 in 2's complement
+12        = 0000 1100

  1110 0100   (−28)
+ 0000 1100   (+12)
-------------
  1111 0000   (no carry out of MSB)

MSB = 1 → the result is negative and is in 2's complement form. Magnitude: 1's complement of 11110000 = 00001111, +1 = 00010000 = 16.

(−28 + 12) = (11110000)2 = −16 ✓

2. Prove the following [2×2]

(a) AB + A'C + BC = AB + A'C (consensus theorem)

LHS = AB + A'C + BC(A + A')   [since A + A' = 1]
= AB + A'C + ABC + A'BC
= AB(1 + C) + A'C(1 + B)
= AB + A'C = RHS ∎

(b) AB + C(A⊕B) = BC + A(B + C)

LHS = AB + C(AB' + A'B) = AB + AB'C + A'BC.
Write AB = ABC + ABC' :
LHS = ABC + ABC' + AB'C + A'BC = Σm(7, 6, 5, 3).
RHS = BC + AB + AC. Expanding each term into minterms: BC = ABC + A'BC (7,3); AB = ABC + ABC' (7,6); AC = ABC + AB'C (7,5). RHS = Σm(3,5,6,7).
LHS = RHS (both are the majority function) ∎

Truth-table verification of (b)

6. 4-bit PISO shift register – data 1101 [3+2]

Operation: the register has a control input SH/LD'. Each D input is fed through a 2:1 multiplexer (AND–OR gates) selecting between the parallel input Pi (SH/LD' = 0, load mode) and the output of the previous FF (SH/LD' = 1, shift mode). With SH/LD' = 0 a clock pulse loads all four bits (1101) in parallel. With SH/LD' = 1 each following clock pulse shifts the data one place towards the output FF-D; the bits appear one after the other at the serial output QD. Serial input of FF-A is tied to 0, so zeros fill in from the left.

Fig: 4-bit PISO register (M = 2:1 multiplexer: 0 → Pi, 1 → previous Q; select = SH/LD').

Fig: timing diagram for parallel data 1101 (PAPBPCPD = 1,1,0,1). First clock (LD mode) loads the data; the next four clocks shift it out. Serial output stream QD = 1, 0, 1, 1 (LSB first).

In the timing diagram the first period (before the load edge) is the initial cleared state.

7. Mod-12 asynchronous counter (positive edge, JK flip-flops) with timing diagram [3+3]

Circuit: four JK flip-flops (J = K = 1) are positive-edge triggered; clock of each following FF is taken from Q' of the preceding FF (up count). Mod-12 means count 0000 (0) to 1011 (11); at the 12th pulse the count would become 1100. The first state in which Q3 = Q2 = 1 is 1100, so a NAND gate with inputs Q3 and Q2 is connected to the active-low CLEAR inputs of all FFs: it clears the counter to 0000 immediately (reset at 12 → sequence 0…11).

Fig: mod-12 asynchronous counter; NAND(Q3,Q2) → CLR.

Fig: timing diagram (ideal). Q0 = f/2, Q1 = f/4, Q2 = f/8; Q3 is high during counts 8–11; the state 1100 lasts only for a few ns (reset glitch). Output of Q3 has period 12 Tclk (frequency f/12).

9. Two-input CMOS NAND gate; characteristics of TTL family [4+2]

Fig: 2-input CMOS NAND – two PMOS in parallel (pull-up) between VDD and Y, two NMOS in series (pull-down) between Y and ground. Inputs A, B connect to both a PMOS and an NMOS gate.

Logic operation

  • A = B = 0: both PMOS ON, both NMOS OFF → Y connected to VDD → 1.
  • A = 0, B = 1 (or A = 1, B = 0): one PMOS is ON (parallel path), the series NMOS path is broken → Y = 1.
  • A = B = 1: both PMOS OFF, both NMOS ON in series → Y pulled to ground → 0.

Thus Y = (A·B)'. In every steady state only one network conducts, so static power is almost zero.

Characteristics of TTL family

  • Built from bipolar transistors (multi-emitter input transistor and totem-pole output); supply VCC = +5 V (±5 %).
  • Logic levels: VIL(max) = 0.8 V, VIH(min) = 2 V, VOL(max) = 0.4 V, VOH(min) = 2.4 V; noise margin ≈ 0.4 V.
  • Propagation delay ≈ 10 ns (standard TTL); power dissipation ≈ 10 mW per gate.
  • Fan-out ≈ 10; totem-pole output gives good drive and fast switching; open-collector and tri-state versions exist.
  • Unused inputs float to logic 1; good speed, but higher power than CMOS.

10. Time-measuring circuit – functional diagram and operation [4]

A digital time-interval meter measures the time between a START pulse and a STOP pulse by counting the number of pulses of a precise clock that occur in between: T = N × Tclk (Tclk = 1/fclk).

START→Signal conditioner
(Schmitt trigger)→Control flip-flop
(Set = start, Reset = stop)→ Q (gate) →AND gate→Decade counters→Latch → Decoder → Display
STOP→ (to reset input of the control FF)  | Crystal oscillator
(1 MHz) + dividers→ clock to AND gate

Operation: (1) Before measurement the counter and control FF are reset. (2) The START pulse sets the control FF; its output enables the AND gate. (3) Clock pulses from the crystal oscillator pass through the AND gate and are counted by the decade counters. (4) The STOP pulse resets the FF, the AND gate closes and counting stops. (5) The count N is latched, decoded and shown on the seven-segment display. Example: with fclk = 1 MHz (Tclk = 1 µs) and N = 2500, the interval T = 2500 µs = 2.5 ms. Resolution = one clock period; accuracy depends on oscillator stability (±1 count error).
