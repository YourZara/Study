(ii) Half adder and half subtractor in one circuit

Half adder: Sum = A⊕B, Carry = AB. Half subtractor: Diff = A⊕B, Borrow = A'B. Sum and Diff are identical. Introduce a mode input M (M = 0 → adder, M = 1 → subtractor):

S/D = A ⊕ B  ,  C/Bo = (A ⊕ M)·B

For M = 0: A⊕0 = A → carry = AB. For M = 1: A⊕1 = A' → borrow = A'B.

Sequence (QCQBQA): 101 → 100 → 011 → 010 → 001 → 000 → 101 (5 down to 0, then back to 5). States 110, 111 unused (don't care). JK excitation: 0→0 (0,X); 0→1 (1,X); 1→0 (X,1); 1→1 (X,0).

For FF-A: JA = 1 in all even states and KA = 1 in all odd states, the rest being don't care → JA = KA = 1 (toggles every clock).

JA = KA = 1;  JB = CA', KB = A';  JC = B'A', KC = A'

6. 4-bit SIPO shift register – input data 1011 [3+7]

Working: four D flip-flops (A, B, C, D) are connected in cascade (QA→DB, QB→DC, QC→DD) with a common clock. Serial data is applied to DA, one bit per clock pulse (MSB first: 1,0,1,1). On every positive clock edge each FF takes the value of the FF on its left, so data moves one position to the right. After four clock pulses the four bits are present simultaneously at the parallel outputs QAQBQCQD – serial-to-parallel conversion. All FFs are cleared before the first pulse.

Fig: 4-bit SIPO shift register (parallel outputs QA, QB, QC, QD).

After the 4th pulse: QDQCQBQA = 1011 – the first bit entered is at QD, the last at QA.

Fig: timing diagram for input 1011 (outputs change at the rising clock edge).

7. 3-bit up/down asynchronous counter, negative-edge triggered clock [3+3]

Principle: three JK (or T) flip-flops in toggle mode (J = K = 1) with negative-edge triggering. FF-A (LSB) receives the external clock. A flip-flop toggles when the previous stage output makes a 1 → 0 transition. Therefore:

  • Up counting: clock of the next FF is taken from Q of the previous FF (falling edge of Q = 1→0 carry).
  • Down counting: clock of the next FF is taken from Q' of the previous FF.

A control input M (M = 1 → up, M = 0 → down) selects the source using AND–OR gates: CLKB = M·QA + M'·QA', CLKC = M·QB + M'·QB'.

Fig: 3-bit up/down ripple counter (FF clock inputs shown for the up mode, i.e. from Q; the two gate networks above select Q or Q' with M).

Fig: timing diagram – UP counting (M = 1): 000 → 111 → 000. Each output changes at the falling edge of the clock/previous output.

Fig: timing diagram – DOWN counting (M = 0): 000 → 111 → 110 → … → 000 (borrow from the 000 state sets the counter to 111).

9. Two-input TTL NOR gate; characteristics of CMOS family [5+2]

Fig: simplified 2-input TTL NOR gate. Q1A, Q1B: input transistors (inputs A, B); Q2A, Q2B: phase-splitter transistors connected in parallel (common collector and common emitter); Q3–D–Q4: totem-pole output; R1–R4: resistors; VCC = +5 V.

Operation

  • A = B = 0: both input transistors conduct and take the base current away from Q2A, Q2B → both OFF. Q4 gets no base current (through R3 → 0) → OFF; Q3 is driven ON through R2 → output = VCC − VBE − VD ≈ 3.4 V = logic 1.
  • A = 1, B = 0 (or A = 0, B = 1): the transistor with input 1 (say Q1A) is reverse-biased, so its collector current drives Q2A ON. Q2A (a parallel path) supplies the base of Q4 and lowers the base of Q3 → Q4 saturates, Q3 is OFF → output ≈ 0.2 V = logic 0.
  • A = B = 1: both Q2 transistors ON → Q4 ON, Q3 OFF → output = 0.

Because the Q2 transistors are in parallel, one input at 1 is enough to make the output 0: Y = (A + B)' (NOR).

Characteristics of CMOS family

  • Built from complementary n-MOS and p-MOS transistors; very low static power (≈ nW–µW), power rises with frequency (P ∝ C·V2·f).
  • Wide supply range (3–15 V for 4000B, 2–6 V for 74HC); logic levels ≈ 0 V and VDD.
  • Very high noise margin (≈ 30–45 % of VDD) and rail-to-rail output swing.
  • Very high input impedance → very large fan-out (> 50 gates, limited by capacitance).
  • Propagation delay ≈ 8–10 ns (HC), slower in the 4000 series; high packing density; needs protection against static discharge; unused inputs must not be left floating.

10. Frequency measurement – functional diagram and operation [4]

The frequency of a periodic signal is the number of cycles per second. A digital frequency meter counts the input cycles N during an accurately known gate time T: f = N / T.

Unknown signal fx→Schmitt trigger
(pulse shaper)→AND (gate)→Decade counters→Latch→BCD-to-7-segment decoder → Display
Crystal oscillator (e.g. 1 MHz)→Decade dividers→Gate control FF (T-FF) – gate time 1 s / 0.1 s / 10 ms→ gate signal to AND; strobe to latch; then reset to counters

Operation: (1) The input is squared by the Schmitt trigger, giving one clean pulse per cycle. (2) The crystal oscillator is divided down by decade dividers to obtain a stable pulse of, say, 1 s, which a flip-flop turns into the gate signal (T = 1 s). (3) While the gate is high, the AND gate passes the input pulses and the counter counts them. (4) When the gate goes low the counting stops, the count N is transferred to the latch (strobe pulse) and displayed; then a reset pulse clears the counter for the next measurement. (5) Example: N = 3250 pulses in T = 1 s → f = 3.25 kHz; with T = 0.1 s the count 325 represents 3.25 kHz (decimal point shifted). Accuracy is decided by the crystal stability and the ±1 count error, so longer gate times give higher resolution.
