8. Digital Integrated Circuits

This chapter bridges the gap between basic electronics and digital logic. You are learning how physical electronic components (transistors) are wired together to create the 1s and 0s (logic gates) you studied earlier.

8.1 BJT and MOSFET Switching Circuits

Transistors can act as amplifiers or switches. In digital logic, we only care about them acting as switches (On/Off = 1/0).

  • BJT (Bipolar Junction Transistor): Current-controlled device. To use it as a switch, it is operated in two regions: Cut-off (Open switch, Logic 1 output if pulled up) and Saturation (Closed switch, Logic 0 output).
  • MOSFET (Metal-Oxide-Semiconductor Field-Effect Transistor): Voltage-controlled device. It consumes much less power than a BJT and is the standard for modern processors. It switches between Cut-off (Off) and Ohmic/Linear (On) regions.

8.2 TTL Parameters (Transistor-Transistor Logic)

TTL is an older logic family built using BJTs. You must memorize these standard definitions, as they are guaranteed exam questions.

  • Voltage Levels: Logic 0 is typically 0V to 0.8V. Logic 1 is 2.0V to 5V.
  • Propagation Delay: The time it takes for a change at the input to produce a change at the output (typically 10ns for standard TTL).
  • Power Dissipation: The amount of power a gate draws (typically 10mW per gate for standard TTL).
  • Fan-in: The number of inputs a gate has.
  • Fan-out: The maximum number of standard inputs that the output of a single gate can drive without dropping the voltage below logic thresholds (typically 10 for TTL).
  • Noise Margin: The maximum noise voltage added to an input signal that does not cause an unwanted change in the output state.

8.3 TTL Circuits: NAND, NOT, NOR

TTL gates are built using multiple emitter BJTs at the input and a "Totem-Pole" output stage.

  • Input Stage: A multi-emitter transistor acts like an AND gate for the inputs.
  • Phase Splitter: The middle transistor controls which output transistor turns on.
  • Totem-Pole Output: Consists of two transistors stacked on top of each other. Only one is ON at a time. The top one pulls the output HIGH (Logic 1), the bottom one pulls the output LOW (Logic 0). Note: Never connect two Totem-Pole outputs together, or it will cause a short circuit.

8.4 CMOS Parameters (Complementary Metal-Oxide-Semiconductor)

CMOS is the modern standard. It uses both p-channel (PMOS) and n-channel (NMOS) MOSFETs.

Parameter TTL CMOS
Power Consumption High (Static power draw) Very Low (Only draws power during switching)
Speed Fast Slower than TTL (but modern CMOS is incredibly fast)
Noise Margin Lower Higher (Better immunity to electrical noise)
Fan-out Low (~10) Very High (Virtually limited only by capacitance, ~50+)

8.5 CMOS Logic Circuits: NAND, NOR, NOT

Every CMOS gate requires a Pull-up Network (PUN) using PMOS, and a Pull-down Network (PDN) using NMOS.

  • NOT Gate (Inverter): One PMOS on top (pull-up to Vdd), one NMOS on bottom (pull-down to Ground). Gates tied together as input.
  • NAND Gate: PMOS transistors in parallel (top), NMOS transistors in series (bottom). If any input is 0, a PMOS turns on (output = 1). If both inputs are 1, both NMOS turn on (output = 0).
  • NOR Gate: PMOS transistors in series (top), NMOS transistors in parallel (bottom).
Exam Tip: If you are asked to draw a CMOS circuit, remember the duality rule. If NMOS is in series, PMOS must be in parallel, and vice versa.

8.6 Three-State TTL Devices

Standard logic has two states: 1 (High) and 0 (Low). Three-state (Tri-state) logic introduces a third state: High-Impedance (High-Z).

  • High-Z State: The output is effectively disconnected from the rest of the circuit. Neither pulling High nor Low.
  • Application: Crucial for bus architectures in computers. If multiple devices share a single data bus, only one device is allowed to output data (0 or 1) at a time. All other devices must be set to High-Z to prevent short circuits and data collision.

8.7 Digital Devices Applications

8.7.1 Multiplexing Displays

If you have four 7-segment displays, controlling them directly requires 28 pins (4 x 7). Multiplexing solves this by tying all the segments (A-G) of the displays together, requiring only 7 data pins plus 4 control pins (to turn on one specific display at a time).

How it works: The microcontroller rapidly flashes each display one by one (e.g., 50 times a second). Human persistence of vision makes it look like all four displays are turned on continuously.

8.7.2 Frequency Counters

A frequency counter measures the frequency of an unknown input signal. It uses a known time base (a highly accurate oscillator) to open a "gate" for exactly 1 second. While the gate is open, a digital counter counts the number of pulses of the unknown signal. The final count represents the frequency in Hertz ($Hz$).

8.7.3 Time Measurements

This is the inverse of the frequency counter. To measure the time width of an unknown pulse, the unknown pulse is used to open the "gate". While the gate is open, the counter counts pulses from a high-frequency, highly accurate internal clock. By knowing the period of the internal clock and the total count, the exact time width of the unknown signal is calculated.
