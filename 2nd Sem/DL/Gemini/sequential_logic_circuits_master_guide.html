5.1 Latches and Flip-Flops: SR, D, T, and JK

A Sequential Logic Circuit is a circuit whose present output depends not only on the present input combinations, but also on the past history of inputs (internal memory state). The memory element forms a feedback loop in the circuit.

Fundamental Distinction: Latch vs. Flip-Flop
  • Latch: An asynchronous, level-triggered storage element. It continuously samples inputs and updates outputs whenever the enable signal ($EN$) is active (High or Low).
  • Flip-Flop: A synchronous, edge-triggered storage element. It changes state only at specific clock transitions (Positive Rising Edge $\uparrow$ or Negative Falling Edge $\downarrow$).

5.1.1 SR Latch (Set-Reset)

The SR Latch can be built using cross-coupled NOR or NAND gates. It maintains a binary state until inputs signal a change.

NAND-Based Active-LOW S'R' Latch

Constructed with cross-coupled NAND gates. Operating modes are activated by driving inputs Low ($0$). Setting $\bar{S}=0, \bar{R}=0$ leads to the invalid state $Q = Q' = 1$.

5.1.2 Clocked / Gated D Latch (Data or Delay)

The D latch eliminates the invalid state of the SR latch by driving $S$ with $D$ and $R$ with $\bar{D}$ through an inverter. It transfers input $D$ directly to output $Q$ when Enable $EN=1$.

5.1.3 JK Flip-Flop

The JK Flip-Flop resolves the forbidden condition of the SR flip-flop. When both $J=1$ and $K=1$, the flip-flop toggles its current output state ($Q_{n+1} = \bar{Q}_n$).

CLKJKQn+1State Description
0 or ↓XXQnNo Change (Clock Inactive)
↑00QnHold / No Change
↑010Reset State
↑101Set State
↑11Q̄nToggle State

5.1.4 T Flip-Flop (Toggle)

The T Flip-Flop is created by shorting inputs $J$ and $K$ together on a JK Flip-Flop ($J = K = T$). If $T=0$, state is held; if $T=1$, output toggles on every active clock edge.

CLKTQn+1Functional Action
↑0QnHold / No Change
↑1Q̄nToggle Output State

5.3 Master-Slave Flip-Flops

5.3.1 The Race-Around Condition in Level-Triggered JK Flip-Flops

In a level-triggered JK flip-flop, if $J = 1$ and $K = 1$ while the clock pulse remains High ($CLK=1$) for a time duration $t_p$ that exceeds the propagation delay $\Delta t$ of the flip-flop logic gates ($t_p > \Delta t$):

1. Output Q changes from 0 to 1 after Δt Toggle condition J=1, K=1
2. Since CLK is still High, new state Q=1 feeds back to gates Feedback loop remains active
3. Output toggles again from 1 to 0 after another Δt Continuous oscillations during tp
4. Final output Q at clock edge becomes unstable & unpredictable Race-Around Condition

5.3.2 Master-Slave JK Flip-Flop Architecture

A Master-Slave Flip-Flop resolves the race-around condition by cascading two clocked SR/JK latches in series with complementary clock signals.

Master-Slave JK Flip-Flop Circuit Diagram
         ┌─────────────────────────┐               ┌─────────────────────────┐
J ──────►│  MASTER JK LATCH        │─── Y (Qm) ───►│  SLAVE SR LATCH         │──────► Q
         │ Active when CLK = 1     │               │ Active when CLK = 0     │
K ──────►│                         │─── Y' (Qm')──►│                         │──────► Q'
         └────────────┬────────────┘               └────────────┬────────────┘
                      │                                         │
CLK ──────────────────┴───────────────[ NOT ]───────────────────┘

Operation Mechanics:

  1. When Clock $CLK = 1$: The Master latch is enabled ($CLK=1$), while the Slave latch is isolated ($CLK'=0$). The Master samples inputs $J$ and $K$ and sets its intermediate state $Y$. The main output $Q$ remains unchanged.
  2. When Clock $CLK$ transitions from $1 \to 0$: The Master latch turns OFF, locking its output state $Y$. Simultaneously, the inverted clock turns the Slave latch ON. The Slave reads $Y$ and updates the main outputs $Q$ and $Q'$.

Because the main output $Q$ changes state only when the master input stage is disabled, feedback cannot re-enter the master stage during the same clock pulse, eliminating the race-around condition.

5.4 Flip-Flop Timing Diagrams

5.4.1 Critical Timing Parameters

  • Setup Time ($t_{su}$): The minimum duration of time that data inputs ($D, J, K, S, R$) must remain stable before the arrival of the active clock edge.
  • Hold Time ($t_h$): The minimum duration of time that data inputs must remain constant after the active clock edge.
  • Propagation Delay ($t_{pd}$): The time delay between the active clock edge trigger and the corresponding output state change at $Q$.

5.5 Flip-Flops as Finite State Machines (FSMs)

Any sequential circuit containing flip-flops and combinational logic can be modeled as a Finite State Machine (FSM). The circuit moves through a discrete set of states based on clock cycles and external inputs.

5.6 Flip-Flop Conversions

Any source flip-flop type can be converted into a target flip-flop type by connecting an appropriate combinational logic circuit to the inputs of the source flip-flop.

Standard Conversion Methodology
  1. Identify the Target FF (desired behavior) and the Source FF (available component).
  2. Construct a composite truth table listing: Target Inputs | Present State ($Q_n$) | Next State ($Q_{n+1}$) | Source Inputs.
  3. Fill in $Q_{n+1}$ using the Target FF's characteristic behavior.
  4. Use the Excitation Table of the Source FF to determine the required Source Inputs for every transition from $Q_n \to Q_{n+1}$.
  5. Minimize expressions for the Source Inputs using K-Maps and draw the logic circuit.

5.7 Flip-Flop Applications

5.7.1 Registers and Shift Registers

A register is a group of flip-flops used to store binary data. Shift registers move stored data bits laterally across stages on every clock pulse.

  • Serial-In, Serial-Out (SISO): Data is loaded and retrieved sequentially, bit-by-bit.
  • Serial-In, Parallel-Out (SIPO): Data enters serially and is read concurrently across all bit positions.
  • Parallel-In, Serial-Out (PISO): Bits are loaded simultaneously via control lines and shifted out bit-by-bit.
  • Parallel-In, Parallel-Out (PIPO): Data is loaded and retrieved simultaneously in a single clock cycle.

Specialized Shift Register Counters:

  • Ring Counter: An $N$-bit shift register with inverted output $Q_N$ connected back to input $D_1$. Requires initial seeding with $100\dots 0$. Total unique states = $N$.
  • Johnson Counter (Twisted Ring Counter): Output $Q_N'$ is fed back to $D_1$. Total unique states = $2N$. Eliminates self-starting issues.

5.7.2 Synchronous and Asynchronous Binary Counters

Asynchronous (Ripple) Counters

The output $Q$ of stage $i$ serves as the clock input for stage $i+1$. Flip-flops switch sequentially, causing accumulated ripple propagation delays.

Synchronous Counters

All flip-flops receive the clock signal simultaneously. Next states are determined concurrently using combinational logic, eliminating ripple delays.

5.7.3 Frequency Division Circuits

A single T Flip-Flop configured with $T=1$ (or D FF with $Q'$ connected back to $D$) toggles state every clock pulse, producing an output square wave with exactly half the clock frequency ($f_{out} = f_{clk} / 2$). Cascading $N$ stages divides clock frequency by $2^N$.

5.7.4 Mechanical Switch Debouncing Circuit

Mechanical switches create contact bounce noises when toggled. An SR Latch filters out voltage spikes during contact bouncing, ensuring clean digital transition pulses.
