Digital Logic & Logic Gates

Comprehensive Engineering Reference & Complete Universal Synthesis Manual

1. Foundations of Digital Logic & Signals

A Logic Gate is an idealized or physical electronic device implementing a Boolean function—a logical operation performed on one or more binary inputs that produces a single binary output.

1.1 Analog vs. Digital Signals

While analog signals vary continuously over a smooth range of voltages, digital logic operates within discrete voltage bands representing binary values:

  • Logic 1 (HIGH / TRUE / ON): Represents the presence of a signal (typically $V_{CC}$ e.g., $+5\text{V}$ for TTL, $+3.3\text{V}$ or $+1.8\text{V}$ for modern CMOS).
  • Logic 0 (LOW / FALSE / OFF): Represents the absence of a signal (typically ground / $0\text{V}$).

1.2 Positive Logic vs. Negative Logic Systems

The assignment of binary state values to physical voltage levels defines the logic polarity:

Logic System Higher Voltage Level ($V_H$) Lower Voltage Level ($V_L$)
Positive Logic (Standard) Logic 1 Logic 0
Negative Logic Logic 0 Logic 1
Duality Principle in Logic Polarity

An active-HIGH gate in positive logic becomes an active-LOW gate in negative logic. For instance, a positive-logic AND gate behaves strictly as a negative-logic OR gate.

4. Universal Gate Synthesis & Step-by-Step Proofs

This section proves universality by constructing all standard logic operations using solely 2-input NAND gates and solely 2-input NOR gates.

4.1 NAND Gate Realization Matrix

1. NOT from NAND (Requires 1 Gate): Connect both inputs together.

Y = (A · A)' = A' // By Idempotent Law: A · A = A

2. AND from NAND (Requires 2 Gates): Invert the output of a NAND gate using a second NAND-based inverter.

Stage 1: Logic Output = (A · B)'
Stage 2: Y = ((A · B)')' = A · B // By Double Inversion Law

3. OR from NAND (Requires 3 Gates): Apply De Morgan's Law $A + B = (A' · B')'$. Invert inputs $A$ and $B$ individually via NAND inverters, then pass both into a 3rd NAND gate.

Inverted Inputs: A' = (A · A)', B' = (B · B)'
Y = (A' · B')' = (A')' + (B')' = A + B // By De Morgan's First Theorem

4. XOR from NAND (Requires 4 Gates): Realizing $Y = A\bar{B} + \bar{A}B$.

Gate 1: G1 = (A · B)'
Gate 2: G2 = (A · G1)' = (A · (A · B)')' = (A · (A' + B'))' = (A A' + A B')' = (0 + A B')' = (A B')'
Gate 3: G3 = (B · G1)' = (B · (A · B)')' = (B · (A' + B'))' = (B A' + B B')' = (A' B + 0)' = (A' B)'
Gate 4: Y = (G2 · G3)' = ((A B')' · (A' B)')' = (A B')'' + (A' B)'' = A B' + A' B = A ⊕ B

5. XNOR from NAND (Requires 5 Gates): Invert the output of the 4-gate NAND XOR circuit using a 5th NAND inverter.

4.2 NOR Gate Realization Matrix

1. NOT from NOR (Requires 1 Gate): Connect both inputs together.

Y = (A + A)' = A' // By Idempotent Law: A + A = A

2. OR from NOR (Requires 2 Gates): Invert the output of a NOR gate using a second NOR inverter.

Stage 1: Logic Output = (A + B)'
Stage 2: Y = ((A + B)')' = A + B // Double Inversion

3. AND from NOR (Requires 3 Gates): Apply De Morgan's Law $A · B = (A' + B')'$. Invert inputs $A$ and $B$ individually via NOR inverters, then pass into a 3rd NOR gate.

Inverted Inputs: A' = (A + A)', B' = (B + B)'
Y = (A' + B')' = (A')' · (B')' = A · B // By De Morgan's Second Theorem

4. XNOR from NOR (Requires 4 Gates): Realizing $Y = AB + \bar{A}\bar{B}$.

Gate 1: G1 = (A + B)'
Gate 2: G2 = (A + G1)' = (A + (A + B)')' = (A + A'B')' = ( (A+A')(A+B') )' = (1 · (A+B'))' = (A + B')'
Gate 3: G3 = (B + G1)' = (B + (A + B)')' = (B + A'B')' = ( (B+A')(B+B') )' = ( (A'+B) · 1 )' = (A' + B)'
Gate 4: Y = (G2 + G3)' = ( (A + B')' + (A' + B)' )' = (A + B')'' · (A' + B)'' = (A + B')(A' + B) = AB + A'B' = A ⊙ B

5. XOR from NOR (Requires 5 Gates): Invert the output of the 4-gate NOR XNOR circuit using a 5th NOR inverter.

5.1 Practical Applications of XOR Gates

  • Controlled Inverter / Programmable Complementer: If input $B$ is held at Logic 0, $Y = A \oplus 0 = A$ (Buffer). If input $B$ is held at Logic 1, $Y = A \oplus 1 = A'$ (Inverter).
  • 1-Bit Half Adder: The Sum output $S = A \oplus B$, while Carry $C = A \cdot B$.
  • Parity Generation & Checking: Cascaded XOR gates yield an output of 1 if the dataset contains an odd number of 1s.

6. Tri-State Logic & High-Impedance (High-Z)

Standard logic gates have two output states (0 and 1). Tri-State Logic adds a 3rd state called High-Impedance (High-Z), where the output is electrically disconnected from the circuit board trace.

7. Standard 7400 Series TTL IC Pinout Reference

Commercial Transistor-Transistor Logic (TTL) ICs come packaged in standard 14-pin Dual In-line Packages (DIP). Pin 7 is always connected to GND ($0\text{V}$) and Pin 14 is connected to $V_{CC}$ ($+5\text{V}$).

7400: Quad 2-Input NAND IC

Contains 4 independent 2-input NAND gates.

  • Gate 1: Inputs (Pin 1, 2) → Output (Pin 3)
  • Gate 2: Inputs (Pin 4, 5) → Output (Pin 6)
  • Ground: Pin 7
  • Gate 3: Output (Pin 8) ← Inputs (Pin 9, 10)
  • Gate 4: Output (Pin 11) ← Inputs (Pin 12, 13)
  • Supply ($V_{CC}$): Pin 14

7402: Quad 2-Input NOR IC

Note: Pin layout reversed compared to 7400!

  • Gate 1: Output (Pin 1) ← Inputs (Pin 2, 3)
  • Gate 2: Output (Pin 4) ← Inputs (Pin 5, 6)
  • Ground: Pin 7
  • Gate 3: Inputs (Pin 8, 9) → Output (Pin 10)
  • Gate 4: Inputs (Pin 11, 12) → Output (Pin 13)
  • Supply ($V_{CC}$): Pin 14

Common 74 Series Logic IC Index

  • 7404: Hex Inverter (6 NOT Gates)
  • 7408: Quad 2-Input AND Gate
  • 7432: Quad 2-Input OR Gate
  • 7486: Quad 2-Input XOR Gate
  • 74133: Single 13-Input NAND Gate

8. Key Electrical Parameters & Characteristics

8.1 Propagation Delay ($t_p$)

The transition time required for an output signal to change state after an input signal transition occurs:

  • $t_{pLH}$ (Propagation Delay LOW to HIGH): Time interval between input trigger and output transition from 0 to 1.
  • $t_{pHL}$ (Propagation Delay HIGH to LOW): Time interval between input trigger and output transition from 1 to 0.
  • Average Delay: $t_p = \frac{t_{pLH} + t_{pHL}}{2}$ (Typical standard TTL: $10\text{ ns}$).

8.2 Fan-In and Fan-Out

  • Fan-In: The maximum number of inputs a logic gate can physically process simultaneously.
  • Fan-Out: The maximum number of standard logic gate inputs that a single logic gate output can reliably drive without voltage degradation outside allowable thresholds.

8.3 Noise Margins

Noise margin quantifies the electrical noise immunity of a logic family:

High-Level Noise Margin: NM_H = V_OH(min) - V_IH(min)
Low-Level Noise Margin: NM_L = V_IL(max) - V_OL(max)

For standard 5V TTL logic: $V_{IH(min)} = 2.0\text{V}$, $V_{OH(min)} = 2.4\text{V}$, $V_{IL(max)} = 0.8\text{V}$, $V_{OL(max)} = 0.4\text{V}$. Yielding a safety noise margin $NM_H = NM_L = 0.4\text{V}$.
